# 受講案内

## はじめに

このページは新規受講者向けに、カリキュラムの目的と受講方法ならびに進行と内容について説明しています。

## 目的

スキルシートに「Linuxのファイル操作」を記載できるレベルを目指します。

## 教材

[こちら](https://cri.terada.click)からアクセスしてください。ただし、毎日23時から翌9時まではサーバーを停止するので閲覧できません。

## 受講方法と進め方

各回の問題集を全問正解してカリキュラム修了となります。想定学習時間は15時間です。

### アカウントの発行

受講にはアカウントが必要です。受講希望の方はSlackで寺田（terada_no-DS）にDMしてください。受講者アカウントを発行します。

### 学習の進め方

「Linux環境構築手順」のページに従い、自分のPCにLinux環境を構築してください。テキストと問題集を用意しています。テキストはハンズオン形式ですので、実際に手を動かしながら学習を進めてください。
毎日9時から23時にサーバーを起動しているので、その時間内であれば好きな時間に受講してかまいません。受講期間中に一度、対面での説明の場を設けます。説明を聞きたい方がいましたら講師（寺田）に声をかけてください。

### 勉強会への参加について

受講期間中に毎週水曜日の勉強会に参加する方は、スキルアップ福岡のチャンネルで**Linux**スタンプを押してください。

### 質問について

勉強会に講師が帰社している場合は対面での質問に対応します。それ以外はSlackのstudy_linuxチャンネルでのチャットまたは寺田（terada_no-DS）にDMしてください。順次対応していきます。

## 学習内容について

「Linuxのファイル操作」に焦点をあてた内容とします。プロセスやネットワークといった内容は範囲外とします。
